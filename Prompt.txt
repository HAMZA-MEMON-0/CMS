## 🌐 MULTI-LANGUAGE SUPPORT (Demo)

### **Implementation Strategy:**

```javascript
// Language data structure
const translations = {
  en: {
    heroHeading: "Empowering Global Communities for Sustainable Change",
    heroSubheading: "Advocacy, Awareness, and Action...",
    // ... more translations
  },
  ur: {
    heroHeading: "پائیدار تبدیلی کے لیے عالمی کمیونٹیز کو بااختیار بنانا",
    heroSubheading: "وکالت، آگاہی، اور عمل...",
    // ... more translations
  },
  ar: {
    heroHeading: "تمكين المجتمعات العالمية من أجل التغيير المستدام",
    heroSubheading: "الدعوة والتوعية والعمل...",
    // ... more translations
  }
};

// Language switcher function
function switchLanguage(lang) {
  document.documentElement.setAttribute('lang', lang);
  
  // Update text content
  document.querySelectorAll('[data-i18n]').forEach(element => {
    const key = element.getAttribute('data-i18n');
    element.textContent = translations[lang][key];
  });
  
  // Update direction for RTL languages
  if (lang === 'ur' || lang === 'ar') {
    document.body.setAttribute('dir', 'rtl');
  } else {
    document.body.setAttribute('dir', 'ltr');
  }
  
  // Store preference
  localStorage.setItem('preferredLanguage', lang);
}
```

### **HTML Structure for Translation:**
